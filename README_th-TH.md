ผมสีน้ำตาลยาวปานกลางของเขาถูกจัดแต่งทรงในสไตล์เสยเรียบไปด้านหลังยาวถึงท้ายทอยและทัดไว้ด้านหลังใบหูอย่างเรียบร้อย มีวอลลุ่มปานกลางที่ส่วนผมปัดด้านหน้าและเรียบแบนที่ด้านข้าง เส้นผมเผยให้เห็นโคนผมสีบลอนด์เข้มและสีน้ำตาลที่ไล่เฉดไปสู่ปลายผมสีบลอนด์สว่าง จัดทรงให้อยู่ทรงแน่นด้วยโพเมดลุคเปียกแบบเข้มข้นที่สร้างประกายเงางาม ดูมีโครงสร้าง พร้อมการแยกตัวของช่อผมเล็กน้อย แนวไรผมที่ไม่สม่ำเสมออย่างเป็นธรรมชาติ และมีเส้นผมชี้ฟูเล็กน้อยมองเห็นได้ที่ศีรษะด้านขวาของเขา บริเวณลำตัวส่วนล่าง มือของเขาประสานกันเบาๆ อย่างผ่อนคลาย โดยมือซ้ายอยู่ด้านล่างและงอนิ้วเข้าด้านในอย่างเป็นธรรมชาติ ขณะที่มือขวากุมข้อนิ้วมือซ้ายไว้อย่างแผ่วเบา เผยให้เห็นแหวนเงินและสร้อยข้อมือโซ่เงิน เขายืนอยู่บนระเบียงที่ทำจากไม้กระดานสีเทาและน้ำตาลอบอุ่นที่ซีดจางวางตัวในแนวทแยง มีฉากหลังเป็นสระว่ายน้ำแบบอินฟินิตี้พูลในระยะกลางที่โดดเด่นด้วยผืนน้ำสีเข้มบริสุทธิ์สะท้อนท้องฟ้ายามพลบค่ำที่มีชีวิตชีวาและเสื้อผ้าสีเข้มของเขา ทางด้านขวาในระยะกลาง ราวระเบียงหินคลาสสิกพร้อมลูกกรงทางสถาปัตยกรรมปรากฏเป็นเงาดำตัดกับผืนน้ำ ขณะที่กิ่งสนในระยะหน้าด้านบนทอดตัวลงมาในเฟรมเบาๆ ใบสนสีเข้มจับขอบแสงแฟลชจางๆ ฉากหลังลึกทอดยาวสู่วิวทิวทัศน์ชายฝั่งอันกว้างใหญ่ที่มีเนินเขาเป็นเงาดำทอดยาวตัดกับท้องฟ้ายามพลบค่ำที่เปี่ยมด้วยบรรยากาศ โดยมีแสงไฟจากอาคารชายฝั่งกระจายตัวส่องแสงนวลๆ อยู่ทางแนวชายฝั่งซ้ายสุด ฉากนี้ส่องสว่างด้วยแสงผสม ผสมผสานอย่างโดดเด่นด้วยแสงแฟลชโดยตรงบนหัวกล้องที่แข็งและให้แสงโทนอบอุ่นสีทองแบบมีทิศทางสูงตกกระทบลงบนตัวแบบ ทำให้เกิดแสงสะท้อนสว่างจ้าบนหน้าผาก สันจมูก โหนกแก้ม แผงอก มือ และเครื่องประดับโลหะ แฟลชที่จัดจ้านนี้สร้างเงาสีดำสนิทที่สั้นและกระชับใต้คาง ภายในรอยพับของเสื้อเชิ้ต และใต้ฝ่ามือที่ประสานกัน ตัดกันอย่างน่าทึ่งกับแสงบรรยากาศสลัวโทนต่ำยามพลบค่ำของฉากหลัง ซึ่งไล่เฉดอย่างนุ่มนวลจากไออุ่นยามพระอาทิตย์ตกดินสีม่วงอมแดงไปสู่ท้องฟ้ายามค่ำคืนสีน้ำเงินกรมท่าเข้มลึก จานสีแบบแยกคู่ตรงข้าม (split-complementary) ของโทนแสงแฟลชที่อบอุ่นตัดกับโทนสีน้ำเงินและสีม่วงของบรรยากาศที่เย็นตาและลดความอิ่มตัวของสี ช่วยปลุกเร้าบรรยากาศของรีสอร์ตหรูหราลึกลับและเอ็กซ์คลูซีฟ บันทึกภาพด้วยสไตล์การถ่ายภาพดิจิทัลที่สมจริงของภาพถ่ายไลฟ์สไตล์ปาปารัสซีระดับไฮเอนด์ ถ่ายในมุมตรงระดับสายตาโดยใช้เลนส์เทียบเท่าระยะ 35 มม. ถึง 50 มม. ใช้เทคนิคเปิดชัตเตอร์ช้าค้างไว้ประมาณ 1/60 วินาที เพื่อสร้างสมดุลระหว่างตัวแบบที่คมชัดกริบกับฉากหลังที่มีแสงน้อย นุ่มนวลกว่าเล็กน้อย และมีสัญญาณรบกวนดิจิทัล (digital noise) การปรับแต่งภาพเน้นสีดำที่ถูกกดให้เข้มขึ้นเล็กน้อยเพื่อคอนทราสต์สูง พร้อมเพิ่มความคมชัดและความชัดเจนบนใบหน้าและเครื่องประดับของตัวแบบ โดยจัดวางองค์ประกอบภาพทั้งหมดอย่างโดดเด่นในรูปแบบภาพบุคคลแนวตั้งอัตราส่วน 3:4
