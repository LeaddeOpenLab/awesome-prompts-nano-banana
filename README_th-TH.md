ข้างหนึ่งคือสีเขียวแห่งความทรงจำ
ที่ยังไม่รู้ตัวว่ามันได้สิ้นสุดลงแล้ว
อีกข้างหนึ่งคือสีฟ้าแห่งคำถาม
ที่ยังมิได้พบปากที่จะเอ่ยถามมันออกมา
พวกมันมองดูเราอย่างที่เวลาเฝ้ามองตัวเอง
เมื่อไม่มีผู้ใดกำลังจับจ้อง
ไร้ความสงสาร ไร้คำพิพากษา
มีเพียงความเอื้ออาทรอันยาวนานของความใส่ใจ
เรามีชีวิตอยู่ในกระแสลมพัดลงชั่วครู่แห่งการโบยบินผ่านของมัน
ช่วงเวลาอันแปลกประหลาดและเปี่ยมด้วยความเมตตา
ที่ซึ่งอดีตยังสะสางกับเราไม่เสร็จสิ้น
และอนาคตได้เริ่มต้นขึ้นแล้ว
ที่จะคิดถึงสิ่งที่เรายังไม่ทันได้สูญเสียไป
ไม่มีสิ่งใดที่ถูกสัญญาไว้นอกจากการหมุนเวียน:
บานพับอันเชื่องช้าและเรืองรองของปีก
ที่เป็นของทุกชั่วโมงในคราเดียว
และไม่เป็นของชั่วโมงใดเลยอย่างสมบูรณ์

มันคือสถานที่ที่สิ่งเหล่านั้นจำกันได้ชั่วครู่

จะคลี่ฝ่ามืออันเงียบสงบและจำเป็นของมันออกมา
